# PokeDex
PokeDex is a application where you can search up the name or ID of any Pokemon and you will get data and stats of that Pokemon. The app uses the [PokeAPI](https://pokeapi.co/) to get data from the internet on each Pokemon when the name is imputed.
</div align="center">


##  How to use the app

### Searching

Start by typing in the name or ID of a Pokemon into the green textbox 

![TexBox](https://github.com/Samsmoke6/PokeDex/blob/main/images/textbox.png)

Click the red button to search

### Viewing the data

After you search, a screen with data for that pokemon should apear

![screen](https://github.com/Samsmoke6/PokeDex/blob/main/images/screen.png)

On the home screen you can see the Name, ID, and elements, as well as a front and back sprite of the Pokemon <br>
You can also view other data from relating to the character using the d-pad <br><br>
You can view:

| Name | Description                                              |
| -----| -------------------------------------------------------- |
| `Stats` | Basic game stats the Pokemon has |
| `Moves` | Every possible move the Pokemon can have |
| `Abilities` | Passive Abilities of the Pokemon |
| `Games` | Every game the Pokemon is in |

You select these options by using the d-pad

![d-pad](https://github.com/Samsmoke6/PokeDex/blob/main/images/d-pad.png)

Click the upper button to move up and the lower button to move down, the center circle is used to select
> The left and right buttons serve no purpose and are only there for asthetic
> 
To return back to the homescreen click the red search button again

# My Process
**This will go into the process of how I made the app**

## The UI

First I created the design of the user interface. I did this on Figma a online web designer, after creating the design I started coding it into my app. To do this I had to learn TKinter, which is a python tool that helps you create the user interface. 

## The Backend Code

After creating the UI, I started on the backend logic of the code. The app used the PokeAPI which stores data on every Pokemon. When you request the data on a Pokemon you get a huge dictionary which has all the data for that specific Pokemon. After I learned how to access the API, I coded all the functions and processes that make the app work as a whole.

## Testing

After completing the app I tested it myself multiple times, and recieved the help of my peers at school to test my app aswell. I found many bugs and errors, which I fixed after discovering.

## Reflection

This app was a personal project and I enjoyed every second of it. From designing the UI to coding it, I learned so much more about code and software development as a whole. I will be doing more of these projects and makking them more complex as I go.
